# RozgarMitra 🤝

**RozgarMitra** is a modern, professional job marketplace application designed for the Indian workforce. It bridges the gap between daily wage workers (Labour) and job providers (Owners), providing a seamless, trusted, and efficient platform for local employment discovery.

## 🚀 Key Features

### 1. Professional Startup & Guest Access
- **Splash Screen**: Clean branding with smooth animations.
- **Guest Browsing**: Explore jobs, search, and view details without mandatory login.
- **On-Demand Auth**: Mobile + OTP authentication is only required for protected actions like applying or chatting.

### 2. Job Discovery Experience
- **Marketplace Home**: Structured layout with sections for **Urgent Jobs**, **Nearby Jobs**, and **Popular Jobs**.
- **Advanced Filtering**: Support for multiple profession selection (OR logic), distance filtering, and wage range.
- **Smart Search**: Dedicated search tab with discovery chips and recent history.

### 3. Worker Features (Labour)
- **Multi-Skill Profile**: Workers can select and manage multiple professions (e.g., Mason, Painter, Electrician).
- **Application Tracking**: Real-time status updates on job applications.
- **Availability Toggle**: Control your visibility to employers with a single tap.
- **ID Verification**: Secure Aadhaar-based verification badge for increased trust.

### 4. Employer Features (Owner)
- **Effortless Job Posting**: Step-by-step form to post urgent or regular jobs.
- **Applicant Management**: View worker profiles, ratings, and skills before hiring.
- **Direct Communication**: Built-in chat thread creation upon application acceptance.

### 5. Tech Stack & Architecture
- **Language**: 100% Kotlin
- **UI Toolkit**: Jetpack Compose (Modern Declarative UI)
- **Navigation**: Jetpack Navigation Component
- **Persistence**: SharedPreferences with a robust `PreferenceManager`.
- **State Management**: StateFlow & collectAsStateWithLifecycle (Lifecycle-aware).
- **Theming**: Full **Dark Mode** support with persistence.
